Each user picks the model that checks the knowledge rules: a "Review model" on the key page, their default model when left blank. It runs their `review`s and the rule checks of their `full-review`s. The configuration's per-mode `models` (`models.review`) are deprecated and ignored: a benchmark on five Podman Desktop pull requests found the free DeepSeek V4.1 Flash as good as Sonnet at it. A pick a run doesn't use no longer refuses it when it loses its price.
